- This is a Vite + React 18 app written in plain JavaScript with ES modules (import/export). Tests are ES modules too. Use double quotes and semicolons.
- Use Vitest with jsdom and React Testing Library. Import test functions explicitly: `import { describe, it, expect, vi, beforeEach } from "vitest";` (globals are not enabled).
- tests/setup.js loads @testing-library/jest-dom matchers (toBeInTheDocument and others) and runs cleanup and vi.clearAllMocks after each test. Do not repeat that in test files.
- Render components with `renderWithProviders` from tests/helpers/renderWithProviders.jsx. It wraps the component in a real Redux store (seed it with `preloadedState`) and a MemoryRouter (`route`, plus `path` for URL params such as "/chat/:targetUserId"). Check Redux changes through `store.getState()` instead of mocking react-redux.
- Never call the real backend. Mock axios with `vi.mock("axios")` and set responses with `axios.get.mockResolvedValue(...)` / `axios.post.mockRejectedValue(...)`. Assert on the URL (BASE_URL from src/utils/constants.js plus the path), the payload and `{ withCredentials: true }`.
- Mock socket connections: `vi.mock("../../src/utils/socket")` (adjust the relative path) and return a fake socket with vi.fn() for `on`, `emit` and `disconnect`. To test incoming events, capture the handler passed to `on` and call it inside `act`. Test src/utils/socket.js itself by mocking `socket.io-client`.
- To test navigation, mock useNavigate: `vi.mock("react-router-dom", async (importOriginal) => ({ ...(await importOriginal()), useNavigate: () => mockNavigate }))`, where `mockNavigate` is created with `vi.hoisted`.
- Use `@testing-library/user-event` for typing and clicking (`const user = userEvent.setup()`). Find elements the way a user would: getByRole, getByText, getByLabelText, getByPlaceholderText. Use findBy* or waitFor for anything that appears after an async call.
- src/utils/constants.js and src/utils/socket.js read `location.hostname` (jsdom uses "localhost"). To cover the non-localhost branches, stub `window.location` (vi.stubGlobal) and load the module again after `vi.resetModules()` with a dynamic `await import(...)`.
- src/main.jsx renders the app at load time: mock `react-dom/client` (createRoot returning `{ render: vi.fn() }`) and `../src/App.jsx`, add a `<div id="root">` to the document, then import main.jsx and assert createRoot and render were called.
- Components log caught errors with console.log. Spy on it (`vi.spyOn(console, "log").mockImplementation(() => {})`) to keep the output clean, and assert on it when that is the only visible effect of an error.
